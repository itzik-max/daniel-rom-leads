# דשבורד הלידים של דניאל רום

דף אחד לניהול הלידים: שם מלא, טלפון נייד, תאריך, תחום העסק, סטטוס (לל"מ 1–8, נקבעה פגישה, אחרי פגישה, נסגר תהליך, לא רלוונטי) והערות.

**האתר:** https://itzik-max.github.io/daniel-rom-leads/

## מה יש בדף
- **מדדים למעלה:** סה"כ לידים, לידים החודש, בטיפול, הגיעו לפגישה (ואחוז מהלידים), נסגרו (ואחוז מהפגישות), לא רלוונטי.
- **פס הסטטוסים:** לחיצה על סטטוס מסננת את הטבלה.
- **הטבלה:** חיפוש, סינון לפי תחום ומיון. את הסטטוס משנים ישר מהטבלה; כל השאר בכפתור "עריכה".
- **טלפון:** לחיצה מחייגת, וכפתור WhatsApp פותח שיחה.
- **ייצוא:** קובץ CSV שנפתח באקסל (מייצא את מה שמוצג אחרי הסינון).
- בנייד הטבלה הופכת לכרטיסים. אפשר להוסיף למסך הבית ("הוספה למסך הבית").

## הקבצים
| קובץ | מה יש בו |
|---|---|
| `config.js` | **מתחילים כאן.** רשימת תחומי העסק, הסטטוסים, ופרטי החיבור ל־Supabase |
| `index.html` | מבנה הדף והטופס |
| `app.js` | ההתנהגות: טעינה, שמירה, מדדים, סינון, ייצוא |
| `styles.css` | העיצוב (כחול לילה וזהב, כמו המותג) |
| `supabase/schema.sql` | הקמת המסד, מריצים פעם אחת |

אין שלב בנייה ואין ספריות. משנים קובץ, דוחפים ל־GitHub, ותוך דקה האתר מתעדכן.

## איפה הנתונים נשמרים
- **לפני חיבור ל־Supabase** (`supabaseUrl` ריק ב־`config.js`): בדפדפן שבו מזינים בלבד. מופיע פס צהוב שמזכיר את זה.
- **אחרי החיבור:** במסד של דניאל, ונגישים מכל מכשיר דרך הקישור עם קוד הגישה (`?k=...`). לידים שהוזנו קודם בדפדפן מועברים למסד בלחיצה אחת.

## חיבור ל־Supabase (פעם אחת)
1. נכנסים ל־https://supabase.com, נרשמים (חינם) ויוצרים פרויקט חדש. אזור: Frankfurt (eu-central-1).
2. בפרויקט: **SQL Editor** → מדביקים את כל `supabase/schema.sql` → **Run**. בסוף מופיע `access_code`. זה קוד הגישה; שומרים אותו.
3. **Project Settings → API Keys** (או Connect): מעתיקים את **Project URL** ואת ה־**Publishable key** (`sb_publishable_...`) ל־`config.js`, ל־`supabaseUrl` ול־`supabaseKey`.
4. דוחפים ל־GitHub. הקישור לעבודה: `https://itzik-max.github.io/daniel-rom-leads/?k=<access_code>`

ה־Publishable key אינו סוד: הוא מיועד לדפדפן, והטבלאות סגורות לגישה ישירה. מה שמגן על הנתונים הוא קוד הגישה, ולכן **אותו לא כותבים בשום קובץ במאגר** (המאגר ציבורי). מי שיש לו את הקישור עם הקוד יכול לראות ולערוך.

להחלפת הקוד (למשל אם הקישור דלף):
```sql
update dr_settings set access_code = encode(extensions.gen_random_bytes(12), 'hex') returning access_code;
```

## איך משנים דברים
- **להוסיף או לשנות תחום עסק / סטטוס:** רק ב־`config.js`. לסטטוס יש `stage` שקובע את הצבע ואת המדדים: `open` (בטיפול), `meeting` (פגישה), `won` (נסגר), `lost` (לא רלוונטי). לא משנים `key` של סטטוס קיים, כי הוא מה שנשמר אצל הלידים.
- **להוסיף שדה** (למשל מייל או מקור הליד): מוסיפים `<label>` עם `name` חדש לטופס ב־`index.html`, ועמודה בטבלה ובכרטיס ב־`app.js` (`renderRows`) ובייצוא (`exportCsv`). המסד לא משתנה, כי כל ליד נשמר כ־JSON.
- **עבודה עם Claude:** פותחים את התיקייה ב־Claude Code ומבקשים בעברית מה לשנות. ההנחיות לקלוד נמצאות ב־`CLAUDE.md`.

## בדיקה מקומית
פותחים את `index.html` בדפדפן, או מריצים מתוך התיקייה `npx serve .` ונכנסים לכתובת שמופיעה.
